# Tic-Tac-Toe

# 🎮 Tic-Tac-Toe (Player vs Player / Player vs Computer)

A simple Tic-Tac-Toe game developed in Python with a **Graphical User Interface (GUI)** using the **Tkinter** library. The game can be played between:
- **Player vs Player** (two players on the same device).
- **Player vs Computer** (player competes against a simple AI).

---

## 🚀 Features

- **Player vs Player Mode**: Two players take turns on the same device.
- **Player vs Computer Mode**: The player competes against a simple AI.
- **Graphical Interface**: Uses Tkinter for the user interface with a 3x3 grid.
- **Win / Draw Detection**: Automatically detects win or draw conditions.
- **Game Reset**: After a win or draw, the game automatically resets.

---

## 🧰 Requirements

- Python 3.x
- Tkinter library (usually bundled with Python)

---

## 📦 Installation

1. Ensure Python 3.x is installed on your system.
2. No need to install additional packages as Tkinter is included with Python by default.
